# پلن سرعت و ایندکس مقالات dadrose.com (بررسی سناریوی SSG)

تاریخ: ۱۴۰۵/۰۷/۲۱ (2026-10-13)

## جمع‌بندی و تصمیم پیشنهادی
- **فعلاً مقاله‌ها رو SSG/Headless نکنیم.** مقاله‌ها همین الان کامل سمت سرور رندر می‌شن (در `/bar-exam-fee/` متن کامل، جدول‌ها و FAQ داخل HTML خام هستن). Elementor 4.3.4 تأیید شد.
- سرعت ایندکس بیشتر به کشف صفحه (سایت‌مپ تمیز، لینک داخلی)، کیفیت محتوا و پایداری/زمان پاسخ سرور بستگی داره. SSG فقط روی زمان پاسخ اثر داره و همین اثر رو با «کش کامل صفحه + CDN» هم می‌شه گرفت.
- SSG رو برای azmoon.dadrose.com (Next.js) و صفحه‌های موضوعی جدید نگه می‌داریم.

|---|---|---|---|

## پلن اجرایی
### فاز ۱: رفع موانع ایندکس (بدون نیاز به تصمیم معماری)
1. تمیز کردن سایت‌مپ‌ها: حذف cart/checkout/login/dashboard و … (F2)
2. حل تکراری‌های `/courses/` و `/product/` (F3)
3. غیرفعال کردن ویدیو-سایت‌مپ خراب `media` (F4)
4. ارسال دوباره سایت‌مپ در Search Console
5. فعال کردن IndexNow در Rank Math (Bing/Yandex)
6. لینک داخلی: هر مقاله جدید حداقل از ۲–۳ مقاله قدیمی مرتبط + صفحه دسته لینک بگیره

### فاز ۲: کش کامل صفحه + CDN
1. تشخیص وب‌سرور هاست (LiteSpeed یا Nginx/Apache)
2. LiteSpeed → LiteSpeed Cache؛ در غیر این صورت → WP Rocket یا کش سمت سرور
3. CDN: ابرآروان یا Cloudflare (برای کاربر ایرانی ابرآروان احتمالاً سریع‌تره؛ **تست‌نشده**)
4. مستثنا کردن صفحات داینامیک و کاربران لاگین‌شده از کش
5. پاک شدن خودکار کش با انتشار/ویرایش مقاله
6. اندازه‌گیری قبل و بعد (TTFB، LCP، Crawl stats)

### فاز ۳: SSG جایی که می‌ارزه
- azmoon.dadrose.com: صفحه‌های `/subjects/[subject]` با `generateStaticParams` و `revalidate` (طبق بخش 5.2 در audit)

### معیار بازبینی تصمیم SSG
اگر بعد از فاز ۱ و ۲ هنوز این‌ها برقرار بود، Headless دوباره بررسی می‌شه:
- میانگین زمان پاسخ در Crawl stats بالای حدود ۸۰۰ms (آستانه پیشنهادی، نه عدد رسمی گوگل)
- یا تعداد زیادی URL با وضعیت «Discovered/Crawled – currently not indexed» که با کیفیت محتوا توضیح داده نمی‌شه

## کارهایی که انجام نشد و دسترسی لازم برای هرکدام
| کار | چرا انجام نشد | دسترسی لازم |
|---|---|---|
| اندازه‌گیری TTFB و هدرهای کش (`curl`) | پراکسی محیط من اتصال به dadrose.com رو رد کرد | باز کردن دامنه‌های `*.dadrose.com` در تنظیمات شبکه محیط، یا خروجی `curl -I` و PageSpeed از سمت شما |
| PageSpeed / Core Web Vitals | سهمیه API عمومی تمام شده بود (429) | کلید API PageSpeed، یا اسکرین‌شات/لینک گزارش PageSpeed |
| Crawl stats و وضعیت ایندکس | دسترسی Search Console ندارم | اتصال GSC (یا خروجی Crawl stats + Pages report) |
| تشخیص هاست/وب‌سرور و افزونه کش فعلی | فقط HTML دیدم، هدر نه | دسترسی پیشخوان وردپرس یا لیست افزونه‌ها + نام هاست |
| زمان پاسخ از داخل ایران | محیط من خارج از ایرانه | تست از داخل ایران (مثلاً با ابزار تست سرعت ایرانی) |
| شمارش دقیق مقالات و صفحات ایندکس‌نشده | سایت‌مپ مقالات در fetch کامل خوانده نشد | همون دسترسی شبکه یا GSC |
